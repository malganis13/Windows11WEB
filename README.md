# Windows11WEB

Полноценная интерактивная веб-ОС в стиле **Windows 11** — в одном файле `index.html`.
Чистые HTML + CSS + Vanilla JS, без CDN, внешних шрифтов и иконок. Работает офлайн.

## Запуск
Просто откройте `index.html` в браузере (или включите GitHub Pages).

## Возможности
- Fluent Design: Mica/Acrylic, тёмная/светлая тема, обои Bloom на CSS
- Рабочий стол, панель задач, меню «Пуск», виджеты, Copilot, центр уведомлений, календарь
- Оконный менеджер: drag, resize в 8 сторон, Snap Layouts, Alt+Tab
- Приложения: Проводник, Терминал, Блокнот, Paint, Сапёр, Косынка, Диспетчер задач, Калькулятор, Параметры, Выполнить
- Виртуальная файловая система в localStorage, звуки на Web Audio API, BSOD

## Горячие клавиши
| Действие | Клавиши | Запасные |
|---|---|---|
| Пуск | Win | Ctrl+Esc |
| Рабочий стол | Win+D | Alt+Shift+D |
| Проводник | Win+E | Alt+Shift+E |
| Выполнить | Win+R | Alt+Shift+R |
| BSOD | Win+Ctrl+Shift+B | Alt+Shift+B |
| Переключение окон | Alt+Tab | Alt+` |

## Исходники
