# Windows11WEB

Интерактивная веб-ОС в стиле **Windows 11** — HTML + CSS + Vanilla JS, без CDN и зависимостей, работает офлайн.

**Скачать готовую сборку (один файл):** [Releases](https://github.com/malganis13/Windows11WEB/releases/latest) → `index.html`.

## Сборка из исходников
```bash
bash build.sh   # создаст index.html из src/
```

## Что внутри
- **Оболочка:** Fluent/Mica, чистый рабочий стол как в Windows 11 (только Корзина), центрированная панель задач, Пуск, поиск, виджеты с **реальной погодой** (Open-Meteo, город по IP), **сетка рабочего стола** — иконки можно перетаскивать по всему экрану, Copilot, быстрые настройки, центр уведомлений, Snap Layouts, Alt+Tab.
- **Темы:** Тёмная, Светлая, Киберпанк (неон), Программист (чёрно-зелёная, хакерская). Все приложения подстраиваются под тему.
- **Звуки:** новые мягкие звуки в духе Windows 11 (вход, уведомления, ошибки и т.п.) на Web Audio.
- **Встроено:** Проводник, Терминал, Блокнот, Paint, Калькулятор, Диспетчер задач, Параметры, Сапёр, Косынка, **Паук**, **Microsoft Edge** (настоящий поиск и сайты), **Microsoft Store**.
- **Microsoft Store:**
  - Браузеры: Chrome, Firefox, DuckDuckGo, Tor, Brave
  - Разработка: VS Code, Visual Studio Community, Sublime Text, Notepad++ (подсветка, расширения, запуск JS/HTML, упрощённый Python/C-подобный код)
  - Творчество: Paint 3D, Blender (G/R/S, Shift+A, F12-рендер, экспорт .obj), FL Studio (секвенсор, piano roll, экспорт WAV), Фоторедактор
  - Игры: **Pony Knight II: Сердце Гармонии** (6 земель, 24 локации, 6 боссов с 2 фазами, сюжет, NPC, дерево навыков, амулеты, лавка, тень после смерти, Новая игра+), **Весёлая ферма 2** (куры, свиньи, овцы, коровы, пекарня, сыроварня, кот-помощник), Нарды, 2048, Змейка, Тетрис
- **Терминал:** `help`, файловые команды, `winget install/uninstall/list`, `theme`, `start`, `weather [город]`, `deskreset`, а также команды для настоящего ПК: `sysinfo`, `battery`, `netinfo`, `mount` (подключить настоящую папку как диск R:), `rls/rcd/rcat/rimport/rexport`, `open`, `search`, `clip/paste`, `notify`, `say`, `fullscreen`.
  Полный список — в файле **Привет.txt** на рабочем столе.

> Браузер по соображениям безопасности не даёт сайтам полностью управлять компьютером. `mount` работает в Chrome/Edge (File System Access API) и только с вашего разрешения.

## Горячие клавиши
| Действие | Клавиши |
|---|---|
| Пуск | Win / Ctrl+Esc |
| Рабочий стол | Win+D |
| Проводник | Win+E |
| Выполнить | Win+R |
| Переключение окон | Alt+Tab / Alt+` |
